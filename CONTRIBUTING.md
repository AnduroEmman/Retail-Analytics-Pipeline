# Contributing to Retail Analytics Pipeline

Thank you for your interest in contributing! Here's how you can help:

## How to Contribute

1. **Fork the repository** on GitHub
2. **Create a new branch** for your feature/fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and test them thoroughly
4. **Commit with clear messages**:
   ```bash
   git commit -m "Add description of changes"
   ```
5. **Push to your fork** and **submit a Pull Request**

## Code Style

- Follow PEP 8 style guidelines
- Use meaningful variable and function names
- Add comments for complex logic
- Ensure code is well-documented

## Testing

Before submitting a PR:
- Run the full pipeline to ensure it works end-to-end
- Test with the sample data in `create_datasales.py`
- Verify data quality checks catch expected issues
- Check that verification returns expected results

## Reporting Issues

- Use the GitHub Issues tab
- Provide clear description and steps to reproduce
- Include Python version and dependencies info
- Share error messages and logs if available

## Questions?

Feel free to open an issue to discuss ideas or ask questions!
